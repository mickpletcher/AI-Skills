## Ask for help

Search [existing issues](https://github.com/mickpletcher/AI-Skills/issues) first. If you still need help, use the [question template](https://github.com/mickpletcher/AI-Skills/issues/new?template=question.yml). Include the skill or file path, host and version if known, what you tried, and the result you expected. A small sanitized example is more useful than a complete private conversation or workflow export.

Use the [issue chooser](https://github.com/mickpletcher/AI-Skills/issues/new/choose) for bugs, feature or skill requests, documentation problems, and accessibility barriers. Blank issues remain available when the forms do not fit or are difficult to use. Support is handled as project capacity allows; there is no guaranteed response time or paid-support service implied here.

## Choose the right reporting route

- Suspected vulnerabilities or exposed secrets: follow [SECURITY.md](SECURITY.md) before sharing details.
- Accessibility barriers or a request for a text alternative: see [ACCESSIBILITY.md](ACCESSIBILITY.md).
- Harassment or other conduct concerns: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- Host billing, account recovery, or a third-party service outage: use that provider's official support.

Issues and pull requests are public. Remove tokens, credentials, private URLs, account identifiers, personal data, and confidential prompts or outputs from reports and attachments. Use synthetic examples whenever possible.
