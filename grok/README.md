# Grok skills

This directory is reserved for future Grok-specific skill adaptations. It currently contains no skill outputs. The generator does not yet support Grok, and no installation or deployment is provided.

Canonical skill definitions live in `../master-skills/`. Platform-specific instructions belong in `../adapters/grok/<skill-name>/append.md`.

Generated Grok candidates should be placed in `../generated/grok/skills/` and validated against the target Grok environment before publishing. Do not assume Grok's consumer app and Grok Build share identical import or execution capabilities.

Existing Claude skills remain unchanged. See [master skill documentation](../master-skills/README.md).
