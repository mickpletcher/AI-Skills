# Design

A Python library owns discovery, YAML schema checks, links, deterministic ZIPs, manifests, and checksums. PowerShell validation commands delegate to it. PR jobs run the same checks on Windows and Linux; branch protection is an owner decision. Behavioral contracts use synthetic local fixtures and a manual rubric; they do not masquerade as model evaluations. Full moved sections are snapshotted by hash. Release preparation is local and blocked by the empty license; the release workflow is an inactive template.
