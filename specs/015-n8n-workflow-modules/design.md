# Design

Keep n8n-workflow as the routing owner. Its short core links workflow patterns, expressions/code, AI design, testing/debugging and runtime/release references. A standard-library Python helper inspects limited graph structure without execution, secret scanning or node-schema claims. Synthetic scenario prompts/rubrics and a local JavaScript example test cover boundary cases without pretending to emulate n8n.

Retain original migration hashes and frontmatter. Record the full intentional original-to-current entrypoint replacement and added-resource hashes. Candidate catalog description changes; shipped files and historical acceptance records do not. Official upstream skills remain optional links with licensing guidance, not installed/copied dependencies.
