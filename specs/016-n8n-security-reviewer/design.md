# Design

New `master-skills/n8n-security-reviewer` contains portable instructions, four focused references, a stdlib-only bounded JSON triage helper, capability/placement metadata and a candidate README. Human/contextual review remains primary. The helper reports known static signals with value-free locators and explicit limitations; no secret validation or runtime proof.

Generate complete candidates using the unchanged repository generator. Add a narrow explicit master-inventory exception; preserve all shipped and prior migration sources, hashes and historical acceptance. Core builder changes occur independently in spec 015 and are not a dependency. Integrating both branches requires normal catalog/manifest reconciliation and regeneration.
