# Requirements

Create a standalone, host-neutral Synthetic Test Data Generator master. Derive fixtures from a supplied schema/test goals or read-only analysis of another AI skill's instructions, contracts, resources and historical evaluations. Maintain traceability to exact source fingerprints, explicitly unresolved oracles, fictional data, bounded sizes, isolated invalid cases, deterministic reproduction, and JSON plus CSV delivery.

The first analysis-derived pilot targets Pi-hole CSV Analyzer with offline known numeric oracles. No live Pi-hole access or target-model execution is required or implied. Preserve existing shipped skills/packages and unrelated working trees. No publication, installation, promotion, merging or external service action.

Change-aware generation beyond staleness detection and failure minimization are later roadmap items, not V1 implementation.
